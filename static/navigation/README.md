Navigation reference data in this directory is used as a routing prior, not as a
mandatory global route network.

Phase 2.7.8 starts with a narrow English Channel / Western Approaches proof of
concept. The MVP layer is a controlled project reference derived for testing
against observed AIS behaviour and public routeing concepts. It is not an
official IMO, UKHO, or EMODnet product and must not be used for navigation.

Candidate production data sources to evaluate before replacing this MVP layer:

- IMO Ships' Routeing Measures: routeing concepts including traffic separation
  schemes, recommended tracks, deep-water routes, areas to be avoided, and
  associated measures.
- ADMIRALTY / UKHO Marine Data Portal: open GIS data for Ships' Routeing
  Measures where available under the portal's current terms.
- EMODnet vessel density: open European vessel-density products suitable for
  deriving route-density corridors after source and license review.
